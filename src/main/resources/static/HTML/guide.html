Fram Vision 이용안내

관리자용 구독 안내와 사용자용 이용 방법을 확인하세요.

관리자용 — 구독 안내

병동/약제팀을 관리하는 관리자 계정은 구독을 통해 Fram Vision의 전체 기능을 이용할 수 있습니다.

Basic

소규모 병동을 위한 기본 플랜

  • 실시간 모니터링
  • 전표 매칭 관리
  • 이상 알림
추천

Pro

여러 병동을 함께 운영하는 관리자용 플랜

  • Basic 플랜 전체 기능
  • 통계 분석
  • 직원(사용자) 등록 및 권한 관리

결제 및 구독 기능은 현재 준비 중입니다. 관리자 계정이 필요하시면 담당자에게 문의해 주세요.

사용자용 — 이용 방법

소속 관리자로부터 계정을 등록받은 사용자는 아래 기능을 이용할 수 있습니다.

1

회원가입 / 로그인

아이디와 비밀번호로 가입 후 로그인합니다.

2

실시간 모니터링 확인

병동의 의약품 이동 현황을 실시간으로 확인합니다.

3

전표 확인 및 이상 알림 대응

매칭 대기·오류 전표와 이상 알림을 확인하고 조치합니다.
