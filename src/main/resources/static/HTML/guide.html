구독 · 권한 관리

관리자

시스템을 구독하고, 함께 사용할 일반 사용자에게 대시보드 접근 권한을 부여하는 사용자입니다.

관리자가 하는 일

  • 시스템 구독 및 구독 관리
  • 하위 사용자에게 대시보드 접근 권한 부여
  • 일반 사용자의 접근 권한 관리

이렇게 시작하세요

  1. 계정 준비

    회원가입 후 로그인합니다.

  2. 시스템 구독

    관리자로서 시스템을 구독합니다.

  3. 사용자 권한 부여

    함께 사용할 일반 사용자에게 접근 권한을 부여합니다.

권한을 받아 서비스 이용

일반 사용자

관리자에게 대시보드 접근 권한을 받아 의약품 관리 업무에 시스템을 사용하는 사용자입니다.

일반 사용자가 하는 일

  • 관리자에게 시스템 사용 권한 요청
  • 권한을 받은 계정으로 로그인
  • 부여받은 권한으로 대시보드 이용

이렇게 시작하세요

  1. 계정 준비

    사용할 계정을 준비합니다.

  2. 관리자에게 권한 요청

    관리자가 해당 계정에 접근 권한을 부여해야 합니다.

  3. 대시보드 이용

    권한 부여 후 로그인하여 업무를 시작합니다.

자주 묻는 질문

일반 사용자도 직접 구독해야 하나요?

구독은 관리자가 진행합니다. 일반 사용자는 관리자가 부여한 권한으로 시스템을 이용합니다.

가입했는데 대시보드에 들어갈 수 없어요.

관리자에게 현재 로그인한 계정의 접근 권한을 확인해 달라고 요청해 주세요. 권한을 받은 계정과 로그인한 계정이 같은지도 확인해 주세요.

사용 권한은 누구에게 요청하나요?

소속 조직에서 시스템을 구독하고 사용자 권한을 관리하는 관리자에게 요청해 주세요.
